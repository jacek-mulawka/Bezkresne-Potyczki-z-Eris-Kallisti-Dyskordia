# Bezkresne-Potyczki-z-Eris-Kallisti-Dyskordia

Gra strategiczna, w której dominia toczą ze sobą potyczki.

Gracz kieruje jednym z zadanej liczby dominiów.
W trakcie potyczki za pomocą wież obserwacyjnych powiększa się terytorium dominia aby uzyskać kontrolę nad surowcami.

Wokół surowców można wybudować do dwóch domków, które rozpoczną wydobycie.

Przeciwnika można zaatakować poprzez wybudowanie koszar. Koszary szkolą jednostki, które automatycznie zmierzają do najbliższego obiektu przeciwnika i rozpoczynają atak.

Wieżami obronnymi można się chronić przed jednostkami przeciwnika.

Po upływie określonego czasu (domyślnie 60 sekund) odbywa się starcie armii. Przed starciem należy zakupić jednostki armii. Do wyboru jest piechota i jazda. Sposób walki jednostek armii (zwarcie, dystans) jest wybierany losowo.
Jednostki tego samego typu można łączyć aby powstała potężniejsza jednostka.

Potyczkę wygrywa się zdobywając zamek przeciwnika lub wygrywając określoną ilość (domyślnie 5) starć armii.

Za zwycięstwo w potyczce otrzymuje się punkty, za które można ulepszyć swoje dominium.

Wynik potyczki wpływa na miejsce w rankingu. Oprócz potyczki, w której uczestniczy gracz przeliczane są potyczki wszystkich pozostałych dominiów.

Każde z dominiów ma wylosowany typ strategi (od agresywnej do zachowawczej). Wraz z odbytymi potyczkami można obserwować, które typy strategii plasują się, na których pozycjach w rankingu.

Dostępna jest aktywna pauza.

Mapy można dowolnie dodawać i edytować w programie graficznym (są to pliki bmp).

Jeżeli przeliczanie potyczki trwa zbyt długo można zmniejszyć ilość dominiów, zmniejszyć wielkość map, zmieniać ilość wątków tworzonych podczas przeliczania.

Nazwy dominiów zostały wygenerowane maszynowo przy użyciu [Google](https://www.google.com/).


## English

A strategy game in which various domains engage in skirmishes.

The player controls one of several available domains.
During a skirmish, players expand their domain's territory using observation towers to gain control over resources.

Up to two structures can be built around resource nodes to begin extraction.

Players can attack opponents by constructing barracks. Barracks train units that automatically advance toward the nearest enemy structure to launch an assault.

Defensive towers can be used to protect against enemy units.

After a set period (60 seconds by default), an army clash occurs. Before this clash, players must purchase army units-choosing between infantry and cavalry. The combat style of these units (melee or ranged) is determined randomly.
Units of the same type can be combined to create a more powerful unit.

A skirmish is won by capturing the opponent's castle or by winning a specific number of army clashes (5 by default).

Winning a skirmish earns points, which can be used to upgrade one's domain.

The outcome of a skirmish affects a player's position in the rankings. In addition to the skirmishes in which the player participates, the results of all other domain skirmishes are also calculated.

Each domain is assigned a random strategy type (ranging from aggressive to conservative). As more skirmishes take place, players can observe how different strategy types perform and where they rank.

An active pause is available.

Maps can be freely added or edited using graphic software (they are stored as BMP files). If the calculation of a skirmish takes too long, you can reduce the number of domains, decrease the map size, or adjust the number of threads created during the calculation process.

The domain names were machine-generated using [Google](https://www.google.com/).
